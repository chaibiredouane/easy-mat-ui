Easy Mat UI: a configurable Angular Material data table

Easy Mat UI is an open-source (MIT) Angular library built on Angular Material. Describe your table in one configuration object and the library provides column filters, search, sorting, pagination, expandable rows, child tables and tabs, a create / edit / view dialog, a multi-select, and light and dark themes.

Features

  • Data table (lib-easy-table) with typed columns, text and multi-select column filters, a pinned header and pagination
  • Child tables and tabs: childConfig takes one configuration, or an array to get tabs
  • Dialog service for create, edit and view forms with text, number, date, text area, dropdown and multi-select fields
  • Reusable multi-select component with search, select-all and clear
  • Light and dark themes switchable at runtime (EasyThemeService), driven by CSS variables
  • Responsive layout and accessibility checks (no WCAG 2 A/AA violation found by axe-core on the demo)

Install

npm install easy-mat-ui-ng20

Supports Angular 20, 21 and 22 (package easy-mat-ui-ng20, the same package for all three).
