# Security Policy

## Supported versions

Each Angular major version has its own package (`easy-mat-ui`, ...). Only the latest minor release
of each supported Angular line receives security fixes.

| Package | Version | Supported |
|---|---|---|
| `easy-mat-ui` | 20.x | Yes |

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Use GitHub's private vulnerability reporting: **Security > Report a vulnerability** on
<https://github.com/chaibiredouane/easy-mat-ui>.

Include a description, reproduction steps and the affected version. You can expect an initial answer
within a few days.
